# 员工手册（节选）

考勤制度：公司实行弹性打卡，员工可在8:30-9:30之间到岗，工作时长满8小时即可下班。迟到超过30分钟记为一次迟到，每月累计迟到3次及以上影响当月绩效。

请假制度：请假需提前在OA系统提交申请。事假需提前1天申请，病假需在当天10:00前提交并提供医院证明。请假3天以内由直属主管审批，3天以上需部门负责人审批。

年假规定：入职满1年可享受5天带薪年假，满3年可享受7天，满5年可享受10天。年假需在自然年内休完，未休完的可顺延至次年3月31日。

报销流程：差旅、办公用品等费用需在发生之日起30天内提交报销单，发票抬头为"星辰科技有限公司"。报销金额500元以下由部门主管审批，500-5000元由财务经理审批，超过5000元需总经理审批。报销到账时间一般为提交后5-7个工作日。

薪资发放：每月10日发放上月工资，遇节假日提前发放。

办公福利：公司提供免费下午茶与健身房，每周五下午为弹性活动时间。
