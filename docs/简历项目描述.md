## 四、企业知识库智能问答 Agent（kb-agent）| 后端开发 | 2026.09 - 至今

基于 Spring Boot + LangChain4j 的企业知识库智能问答 Agent，通过大模型函数调用（Function Calling）
自主决策调用工具，回答公司制度、产品、流程等知识库问题，用于智能客服/内部助手场景。

- **Agent 循环**：使用 LangChain4j AiServices 实现"模型-工具"自动循环，模型可自主调用
  知识库检索、当前时间、安全计算器、天气查询 4 个工具并基于工具结果作答；
- **RAG 检索**：自研 TF-IDF + 余弦相似度中文检索（中文 2-gram 分词，无第三方分词依赖），
  文档按段落切块后建索引，检索 Top3 片段作为作答依据，显著降低模型幻觉；
- **模型解耦**：不绑定单一厂商，通过配置 baseUrl/Key/模型名即可切换 DeepSeek、通义千问、
  智谱、豆包等 OpenAI 兼容大模型；会话记忆用 MessageWindowChatMemory 维护多轮上下文；
- **工程化**：天气工具支持 mock/真实双模式（离线可演示），计算器使用自研递归下降解析器
  杜绝表达式注入，工具调用过程可视化，提供 REST 接口与网页聊天界面；
- **质量**：16 个单元测试覆盖检索、计算、工具与接口逻辑；`mvn package` 打成单一 jar 即可部署。
